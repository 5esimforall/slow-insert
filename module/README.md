# Slow Insert v0.6.13

依赖 Quick Insert 的右侧常驻速查面板。显示来源徽标，支持打开条目和原生拖放，不修改 Quick Insert 本身。

## 环境与安装

- Foundry VTT v13（开发目标 13.351）。
- Quick Insert ≥ 3.7.8；适配与源码检查基于 3.7.8。
- 三套专用速查针对 D&D5e 5.2.5。其他系统只显示「全部物品」的类型、来源筛选。

把 `slow-insert` 文件夹放入 Foundry 用户数据的 `Data/modules`，重启 Foundry，在世界的模块管理中启用 Quick Insert、真实视觉 · Truesight 与 Slow Insert。更新后需要重载客户端，才能注册新增的索引字段。

没有在线更新地址；这是本地发行版。安装和更新不改变世界条目或模块启用状态。

## 配色

侧栏与筛选排序浮窗复用 Quick Insert 的背景、悬停、选中和焦点配色：浅色主题采用浅灰背景与淡橄榄色强调，深色主题采用深灰紫背景与淡紫色强调。文字与原生控件跟随 Foundry 的主题，警告、首选星标和筛选提示分别适配明暗底色；不修改 Quick Insert 或其他窗口的样式。

## 本地化

界面、筛选选项、提示、通知和无障碍标签跟随 Foundry 的语言设置，提供英文与简体中文（`en`、`cn`，兼容 `zh-CN` / `zh-Hans`）。切换 Foundry 语言后重载客户端即可生效；其他语言使用 Foundry 的英文回退。条目名称、正文和合集名称仍尊重原文档及已有翻译模组，不做二次翻译。系统条目类型优先使用系统的本地化标签。来源缩写如 `PHB'14` 保持稳定，切换语言不会丢失筛选选择。

## 规则版本

在 Foundry「配置设置 → Slow Insert → 规则版本」选择显示范围。默认跟随当前世界的 D&D5e 规则；也可以为当前客户端选择 5e 或 5r。5e 隐藏已确认的 2024 内容，5r 同时显示两代内容。未知与版次冲突的条目保留，其他筛选照常生效。修改后侧栏和弹出窗口立即刷新。

## 速查方案

在查询页标题栏或「筛选与排序」区域中切换速查方案。两处选择同步，切换后保留搜索文字，并恢复所选方案的筛选与排序。

界面与分类参考本地 **5e 不全书 → 本书速查**，不再使用 v0.0.2 的三态标签。

| 方案 | 筛选组 |
| --- | --- |
| 全部物品 | 条目类型、来源 |
| 万法大全 | 时间、环阶、学派、职业、来源、必须具备、必须不具备 |
| 万器大全 | 稀有度、类别、同调、来源 |
| 万兽大全 | 挑战等级范围、传奇动作、体型、生物类型、来源 |

- 普通分组默认全选；同组为 **OR**，不同组为 **AND**。「清空」表示该组不选任何项，因此没有结果；「全选」恢复不限。
- 「必须具备／必须不具备」位于筛选末尾，默认不勾选。「必须具备」要求具备所有勾选属性；「必须不具备」要求不具备任何勾选属性。属性包括专注、仪式、言语／姿势／材料成分，以及有价值或会消耗的材料。
- 时间分为动作、附赠、反应、其他；缺失字段单列「未知」，不冒充其他。
- 挑战等级支持 0、1/8、1/4、1/2、1–30，范围含边界；最小值大于最大值时自动交换。「不限」会保留未知 CR，指定范围则不包含未知 CR。
- 每套方案分别记住选择。顶部「重置」只重置当前方案，不清除搜索文字或其他方案。
- 「来源」可按文字查找选项。来源列表从 Quick Insert 已允许索引的完整结果构建，不限于前 100 项。
- 可只用筛选，不输入名称。筛选先执行，再按每批 100 组连续加载结果。

## 数据映射与未知值

**仍以当前 Foundry 世界／合集的实际文档为搜索和拖放对象，不导入不全书条目。**

法术环阶、学派、施法时间、成分、材料成本／消耗；魔法物品稀有度、同调；怪物 CR、体型、类型、传奇动作均读取 Foundry 元数据。

Foundry 的 `sourceClass` 不是完整的职业可学法术列表，因此不用它推断职业。包内 `data/quick-reference.mjs` 从用户指定的本地速查页提取了**名称、来源、职业与魔法物品分类事实**，用于：

- 以规范化后的 **完整名称（中文、英文或中英合名）／identifier ＋明确来源** 精确匹配职业列表。
- 精确匹配魔法物品的速查分类，必要时补齐缺失的稀有度和同调数据。例如 Foundry 中的武器文档可以在不全书里归为法杖。
- 不进行模糊名称匹配，不跨版本猜测；分类有冲突、来源不明、无法匹配时标为「未知」。原表明确无职业的条目才属于「无职」。

只打包上述分类事实，不包含规则正文、原页面脚本或 HTML；运行时不读取本地参考目录，也不联网。四个参考页、校验和及提取数量见 `data/provenance.json`。原表中来源不唯一的行会跳过；这不是覆盖所有自制条目的完整数据库。

万器方案只包含有稀有度、魔法属性或精确速查记录作为依据的物品。无法准确映射的类别显示「未知」，不会按名字猜测。万兽方案只包含 Quick Insert 可见的 **NPC Actor**，不混入玩家角色。

未知来源单列为「来源书籍未知」，不再把合集名称当书名；合集、提供方和原始引用保留在提示中。未知成分数据不会被解释为「无成分」。来源徽标区分 `PHB'14` 与 `PHB'24`；悬停可查看完整来源和页码。

## 排序

「筛选与排序」区域只保留多级排序编辑器，最多设置三级字段，各自选择升降序。拖拽行首数字到另一行可调整优先级；聚焦数字后也可使用 ↑/↓ 或 Home/End 键移动。字段、方向与名称顺序保持不变，修改即时生效，各速查方案分别记忆。

「恢复自动」在有搜索词时使用相关度，无搜索词时按方案使用名称、环阶、稀有度或挑战等级；手动排序不随搜索词变化。

## 操作

- 点击右侧 **Slow Insert** 或在画布有焦点时按 **Ctrl+Alt+Space**；快捷键可在 Foundry 控制设置中修改。
- 点击条目或用 ↑/↓、Enter 打开文档。
- 拖放物品到兼容角色卡；拖放怪物到画布等兼容目标。传递原生 Item／Actor UUID 数据，目标端仍负责权限与导入处理。
- 面板在打开文档、点击外部和拖放后保持展开。Esc 交由 Foundry 处理，Slow Insert 不拦截、转发或自行收起侧栏。
- 侧栏负责标签切换、展开和收起；右键标签可弹出原生搜索窗口。切换标签保留搜索、筛选、展开状态和已加载结果；搜索文字在离开标签时保存。
- 搜索与筛选排序区域顶部的双向箭头可完全对调布局：搜索结果移至浮窗，筛选排序移至侧栏；再次点击换回。当前客户端记住布局选择，切换保留搜索词、条件、排序、展开状态、已加载结果与可用范围内的滚动位置。
- 浮窗由原生宿主管理，可单独移动、调整大小并保存位置。筛选排序放入窄侧栏时改为单列；关闭搜索浮窗后，点击侧栏顶部的搜索按钮或快捷键可重新打开。切到其他侧栏标签不关闭搜索浮窗。
- 刷新图标重建 **Quick Insert 共享索引**，可能需要等待；不会加载整套文档正文来筛选。

v0.0.2 的三态筛选与新复选框语义不同，升级时一次性重置旧筛选；搜索文字、宽度不重置。

## 边界

- Slow Insert 注册为原生侧栏标签，与聊天等标签共用 Foundry 侧栏；搜索和筛选排序可交换承载位置，浮窗的移动、缩放和关闭由 Foundry 管理。
- 不实现 Quick Insert 的命令、`@` 过滤器或富文本编辑器上下文插入；归并只影响显示，不进行破坏性去重。
- 遵守 Quick Insert 的可见来源和 GM-only 限制。原 Quick Insert 快捷键与弹窗不变。
- 不承诺 Foundry v14 或所有 UI 模组兼容。自动浏览器测试使用模拟环境，不等同于真实世界端到端测试。

## 归组与真实视觉 · Truesight

从 v0.6.8 起，来源解析、法术身份聚类及审核状态由独立插件 Truesight 管理。Slow Insert 负责搜索、筛选、成员展示、首选和取用，不再自行计算成员关系。中文名称适配也读取同一公共目录。

在「筛选与排序」点击带外链图标的「归组管理 · Truesight」打开独立审核窗口，预览后明确应用。Slow Insert 不再显示审核状态、撤销或恢复排除等管理控件。也可直接从 Foundry 设置打开管理窗口，不必启用 Slow Insert。详细判定、状态及公共 API 见 Truesight 随包说明。

首选作为 Slow Insert 的个人偏好保留，不参与身份判断。审核按世界、用户和浏览器客户端隔离，不是共享世界设置。

显示全部副本、搜索、筛选与首选只改变浏览结果。「保持独立」则是身份纠错，提交到 Truesight 后会同时影响名称解析；「恢复排除成员」及「撤销」在 Truesight 窗口内管理，撤销不回滚个人首选。

2014 与 2024 分开；来源冲突、未知身份及证据变化条目保持独立。索引刷新不扩大已确认组。接口失败会明确显示错误，不偷偷改用本地计算。打开和拖放仍使用所选原始条目及其原生数据，不改写文档。

## v0.1.1：SRD 默认降级

- 同组默认与展开顺序：手动首选最高；非 SRD 条目在前，SRD 5.1／5.2 等来源最低；同级沿用原有出版方、语言与稳定顺序。
- 根据条目来源与合集元数据识别 SRD，不把所有 dnd5e 系统条目或带 SRD 许可标记的实现一概降级。
- 不改变归组边界、规则版本和 Quick Insert 的跨组相关性排序，不删除 SRD。仅剩 SRD 或明确将其设为首选时仍可使用。

## v0.1.2：同组非 SRD 自动化优先

- 默认项与展开顺序统一为：手动首选 ＞ 非 SRD 自动化条目 ＞ 非 SRD 普通条目 ＞ SRD；同级沿用出版方、语言与稳定顺序。
- 自动化识别读取当前小索引中的 CPR `flags.chris-premades.info.identifier` 或 GPS `flags.gambits-premades.gpsUuid`。仅有包名或成长依赖不算自动化；标记不保证当前环境中全部功能可用。
- 手动首选、来源筛选、归组校验和原始 UUID 不变；被筛掉的自动化成员不会被选作默认，SRD 不因自动化而越级。

## v0.1.3：来源筛选默认收起

- 初次打开或切换速查方案时，“来源”分组默认收起，其他筛选分组不变；点击标题可手动展开。
- 同一方案重建索引／刷新选项时保留手动展开状态。折叠不清空已选择的来源，现有筛选仍生效。


## v0.2.0：规范书目与可扩展来源识别

- 来源分为「规则书与出版物」和「待确认」。书名别名与页码引用共用出版物 ID，例如 `TCE`、`TCoE`、完整书名，以及同一本书的不同页码，不再各占一个来源选项。
- 区分书籍版次、规则代际与出版年份。`PHB'14` / `PHB'24` 不合并；官方 Foundry 的 `MM 2024` 对应 `MM'25`，属于 2024 规则代际，不是凭出版年份推算。
- 自定义来源不再无条件覆盖结构化 `source.book`：版本号、模块名等注记留在提示，不生成新书目。缺失书籍时可使用合集或单书模块的显式书目声明；普通合集标题不是书目证据。
- `VGM/MPMM` 等多书引用拆为多个可筛选来源，同一条目可以匹配其中任一本。每个书目计数均去掉条目内重复引用，但不进行文档去重。
- 只有可用元数据相容时才归入确定版次。泛称核心书可用 `rules` 字段消歧，提示明确说明这一依据；页码自身不决定年代。明确书名版次、结构化／自定义字段或规则代际相互矛盾时进入独立的冲突项，不进入任一确定版次筛选。无版本证据的泛称书归入「PHB · 版次待确认」等项目。
- 原始书名、页码、规则字段、合集和提供方仍可在条目提示中查看。未知／冲突条目仍可搜索、打开与拖拽，不会删除或改写文档、UUID、Quick Insert 原始索引或导入 payload。
- 外部导入条目的书目与导入渠道分离：同一个书目筛选可包含原生与外部检索项，行徽标仍标明「外部」。不再把所有外部书籍共用一个世界来源键；外部条目仍不参加已有的合集审计副本组。
- SRD、Basic／Free Rules、UA 和已知第三方出版物保留各自身份，不冒充 PHB 或正式官方规则书。
- 升级时只重置旧版「来源」选择，避免将旧页码／合集键误解为新书目键。其他筛选、当前方案、宽度、搜索文字和归并首选保留。

### 分层与扩展契约

识别逻辑不含具体条目名、UUID、包名分支或逐页替换规则：

1. `scripts/publications.mjs`：纯书目注册表与引用解析。支持大小写、标点、页码、多来源；从已注册完整书名生成常用首字母缩写。别名碰撞保留歧义，不模糊纠错。
2. `scripts/source-resolution.mjs`：读取证据、消歧和冲突判定，不依赖 DOM 或 Foundry 全局对象。每轮索引使用独立 WeakMap 缓存，不在搜索时加载完整文档。
3. `scripts/source.mjs`：本地化标签、筛选键与提示。筛选与法术速查匹配复用规范出版物 ID，不再维护两套别名逻辑。
4. `data/publications.mjs`：小型离线书目基础数据（身份、完整书名、核心版次及必要别名），不是本机条目纠错清单。新书不要求新增解析分支。

注册表自动吸收系统的 `CONFIG.DND5E.sourceBooks`、活动模块的 `flags.dnd5e.sourceBooks`、合集的显式 `sourceBook`。如已存在 5etools 风格的 `Parser.SOURCE_JSON_TO_FULL` / `SOURCE_JSON_TO_ABV`，可选适配器会读取其书目字典；没有该导入器也能工作，不联网或动态导入它的代码。导入器 `PHB` 代码的 2014 语义仅用于外部来源上下文，不把原生泛称 PHB 擅自判成旧版。

其他模块可以在自身清单中声明 `flags.truesight.publications`，或在 Truesight 就绪后使用：

```js
const unregister = game.modules.get("truesight").api.catalog.registerPublications("my-module", [
  { id: "my-almanac", label: "MA", title: "My Almanac", aliases: ["我的年鉴"] }
]);
// 只更新本客户端的派生书目与筛选，不保存世界设置或修改原始条目。
// unregister(); 或 api.unregisterPublications("my-module");
```

记录必须有稳定的 `id`、显示缩写 `label`、完整 `title`；可选 `aliases`、`externalCodes`、`category`、`year`。存在多个版次时以不同 `id` 和共同 `family`、`familyLabel`、`familyAliases` 声明；`rules` 为 `2014` 或 `2024`。仅在出版物身份确实限定该规则代际时设置 `strictRules: true`，不要把所有旧扩展书与 2024 规则并用都判为冲突。ID 是身份契约，不要为不同书重复使用同一 ID。

### 可确认范围

此功能核对的是**当前可见索引的来源元数据**，不是全文考据。它不能从只有一个、但实际填错的 `rules` 字段证明正文所属版本，也不因两个不同条目用了相同页码就推断它们来自同一版。无证据时保留待确认；有相互矛盾的证据时隔离，不静默修正文档。`PHB 2924` 等疑似错字不会靠相似度自动改为 2024；可通过书目提供方添加经过审核的独立事实或别名。

仅使用既有离线报告重放分类：

```sh
node tools/audit-sources.mjs output/dedup-audit-2026-11-01 output/source-classification-v0.2.0
```

该工具不读取原始数据库。浏览器夹具：`http://127.0.0.1:4178/tests/fixture.html?sources=1&lang=cn`，涵盖分页、版本冲突、未知、别名、多书、外部来源和动态扩展。
